Política de privacidad

Versión del 5 de noviembre de 2026.

Responsable y finalidad

El administrador del proyecto Código Universo gestiona esta herramienta para preparar sus documentales y almacenar copias para revisión en Google Drive. Se destina al uso del administrador autorizado.

Datos y permisos

La aplicación solicita únicamente el alcance de Drive https://www.googleapis.com/auth/drive.file. Este permite trabajar con archivos creados por la aplicación o que el usuario autorice expresamente para ella. Dentro de ese conjunto, el permiso permite crear, leer, modificar y eliminar archivos. El flujo preparado crea archivos y carpetas y lee los resultados para verificar la transferencia.

Los datos tratados comprenden el contenido de los MP4, los nombres e identificadores de archivos y carpetas, tamaños y huellas digitales de integridad. Se utilizan exclusivamente para entregar, organizar, evitar duplicados y comprobar los documentales.

Google gestiona el inicio de sesión y entrega credenciales OAuth de acceso y renovación. La contraseña de Google se introduce en las páginas de Google. La configuración OAuth incluye el identificador y secreto del cliente propio de Código Universo.

Almacenamiento y proveedores

Google almacena los archivos en Drive. GitHub almacena el código privado, los resultados del montaje y los registros de ejecución. La configuración OAuth se guarda como secreto cifrado del repositorio privado y se utiliza durante las ejecuciones autorizadas. Quienes administran el repositorio y sus flujos deben considerarse personas con capacidad de utilizar esas credenciales.

Durante la autorización inicial, el asistente procesa el JSON OAuth seleccionado y la configuración temporal en el Mac del administrador. El JSON descargado permanece en la ubicación elegida por el administrador. Los archivos temporales del asistente se eliminan al finalizar normalmente o al producirse un error controlado.

Durante una ejecución, rclone utiliza una configuración temporal para comunicarse con Google Drive. Los registros pueden incluir nombres de archivos, resultados de transferencia y huellas de integridad. El sitio informativo público contiene exclusivamente la presentación y estas políticas.

Google y GitHub procesan los datos necesarios para prestar sus servicios, conforme a sus propias condiciones y políticas, y pueden utilizar infraestructura en distintos países. Rclone se ejecuta en el equipo o entorno de GitHub que realiza la transferencia.

Conservación y eliminación

Las copias de Drive permanecen hasta que el administrador las elimine. Los artefactos y registros de GitHub se conservan durante los plazos configurados en el repositorio y la plataforma. Las credenciales se conservan como secreto mientras la conexión esté habilitada, hasta su eliminación o revocación.

El administrador puede eliminar los videos desde Drive y las copias o registros desde GitHub. Al solicitar la eliminación de los datos, se revisan ambos destinos y las copias locales existentes. Los proveedores pueden conservar respaldos o registros conforme a sus propias políticas.

Control de la autorización

El acceso se puede revocar desde las conexiones de terceros de la cuenta de Google. Para retirar por completo la conexión, el administrador debe además eliminar el secreto correspondiente de GitHub y las credenciales locales. Revocar el acceso detiene futuras operaciones autorizadas; los archivos ya almacenados se eliminan por separado.

Uso limitado

Los datos de Google se utilizan para las funciones de entrega y comprobación descritas. Se excluyen de la venta, la publicidad, el perfilado comercial y el entrenamiento de modelos generales de inteligencia artificial. El acceso humano queda limitado al administrador y al soporte expresamente autorizado cuando sea necesario.

El uso y la transferencia de información recibida de las API de Google se ajustarán a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.
