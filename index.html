Ciencia para mirar más allá.

Código Universo crea documentales breves sobre ciencia, naturaleza, universo y fenómenos extraordinarios para su página de Facebook.

Una herramienta para preparar documentales

La aplicación de Código Universo está destinada al administrador del proyecto. Su función es preparar videos y guardar los MP4 terminados en Google Drive para su revisión editorial. La conexión de Drive se encuentra en fase de configuración y validación.

El sistema utiliza GitHub Actions para ejecutar el montaje y rclone para transferir los archivos a Drive. La publicación en Facebook requiere una aprobación independiente del administrador.

Por qué solicita acceso a Google Drive

La autorización permite crear la carpeta de revisión, guardar videos, consultar sus nombres y tamaños y leerlos de nuevo para comprobar que la transferencia fue correcta.

Se solicita el permiso https://www.googleapis.com/auth/drive.file. Su alcance se limita a los archivos creados por la aplicación o que se compartan expresamente con ella. La conexión preparada utiliza los archivos y carpetas creados por la propia aplicación.

El consentimiento se realiza en Google mediante un cliente OAuth propio de Código Universo. El sitio sirve para explicar la aplicación y sus prácticas de privacidad.
